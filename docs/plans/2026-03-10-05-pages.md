# 05 - Pages: get, create, update, properties, move, markdown

## References
- OpenAPI spec: `docs/openapi.json` (endpoints: /v1/pages/*)
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Implement `notion-cli page get <page_id>` - retrieve a page
- Implement `notion-cli page create` - create a new page
- Implement `notion-cli page update <page_id>` - update page properties
- Implement `notion-cli page property <page_id> <property_id>` - get page property
- Implement `notion-cli page move <page_id>` - move page to new parent
- Implement `notion-cli page markdown <page_id>` - get page as markdown

## Context
- Depends on plans 01 (foundation), 02 (API client), 03 (output)
- Page object has: id, parent, properties, icon, cover, archived, url
- Properties are complex nested objects (title, rich_text, number, select, etc.)
- Create requires parent (database_id or page_id) and properties
- Update accepts partial properties

## Technical Details
- Page struct: id, object, created_time, last_edited_time, parent, archived, url, properties, icon, cover
- Properties: map[string]PropertyValue (complex union type)
- POST /v1/pages - body: { parent, properties, children?, icon?, cover? }
- PATCH /v1/pages/{page_id} - body: { properties?, archived?, icon?, cover? }
- GET /v1/pages/{page_id}/properties/{property_id} - paginated
- PUT /v1/pages/{page_id}/move - body: { parent }
- GET /v1/pages/{page_id}/markdown - returns markdown string
