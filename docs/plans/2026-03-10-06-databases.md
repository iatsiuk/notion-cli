## Technical Details
- Database struct: id, object, title, description, properties (schema map), parent, url, archived
- Property schema: type-specific config (title, rich_text, number, select, multi_select, date, etc.)
- POST /v1/databases/{id}/query - body: { filter?, sorts?, start_cursor?, page_size? }
- Filter: compound (and/or) or property-level filter objects
- Sorts: array of { property, direction } or { timestamp, direction }
