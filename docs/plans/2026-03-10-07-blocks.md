## References
- OpenAPI spec: `docs/openapi.json` (endpoints: /v1/blocks/*)
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Implement `notion-cli block get <block_id>` - retrieve a block
- Implement `notion-cli block update <block_id>` - update a block
- Implement `notion-cli block children <block_id>` - list child blocks
- Implement `notion-cli block append <block_id>` - append child blocks
- Implement `notion-cli block delete <block_id>` - delete a block

## Context
- Depends on plans 01 (foundation), 02 (API client), 03 (output)
- Block types: paragraph, heading_1/2/3, bulleted_list_item, numbered_list_item, to_do, toggle, code, image, etc.
- Blocks are recursive (children can have children)
- Children endpoint is paginated

## Technical Details
- Block struct: id, object, type, has_children, archived, created_time, last_edited_time
- Type-specific fields: paragraph.rich_text, heading_1.rich_text, code.rich_text+language, etc.
- GET /v1/blocks/{block_id} - retrieve
- PATCH /v1/blocks/{block_id} - update type-specific content
- GET /v1/blocks/{block_id}/children - paginated list
- PATCH /v1/blocks/{block_id}/children - append (body: { children: [...] })
- DELETE /v1/blocks/{block_id}/children - delete
