# 04 - Users: me, list, get

## References
- OpenAPI spec: `docs/openapi.json` (endpoints: GET /v1/users/me, GET /v1/users, GET /v1/users/{user_id})
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Implement `notion-cli user me` - get current authenticated user
- Implement `notion-cli user list` - list all workspace users (paginated)
- Implement `notion-cli user get <user_id>` - get specific user by ID

- User object has: id, type (person/bot), name, avatar_url, person.email or bot.owner
