# 12 - OAuth: token, introspect, revoke

## References
- OpenAPI spec: `docs/openapi.json` (endpoints: /v1/oauth/*)
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Implement `notion-cli oauth token` - exchange code for access token
- Implement `notion-cli oauth introspect` - introspect an access token
- Implement `notion-cli oauth revoke` - revoke an access token

## Context
- Depends on plans 01 (foundation), 02 (API client), 03 (output)
- OAuth flow: user authorizes app -> redirect with code -> exchange code for token
- These commands support integration development/debugging
- Token endpoint uses Basic auth (client_id:client_secret)

## Technical Details
- POST /v1/oauth/token - Basic auth, body: { grant_type: "authorization_code", code, redirect_uri }
- Response: { access_token, token_type, bot_id, workspace_id, workspace_name, workspace_icon, duplicated_template_id, request_id, owner }
- POST /v1/oauth/introspect - body: { token }
- POST /v1/oauth/revoke - body: { token }
