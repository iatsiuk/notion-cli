# 08 - Comments: list, create, get, delete

## References
- OpenAPI spec: `docs/openapi.json` (endpoints: /v1/comments/*)
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Implement `notion-cli comment list --block <block_id>` - list comments on a block/page
- Implement `notion-cli comment create` - add a comment
- Implement `notion-cli comment get <comment_id>` - get a comment
- Implement `notion-cli comment delete <comment_id>` - delete a comment

## Context
- Depends on plans 01 (foundation), 02 (API client), 03 (output)
- Comments are attached to blocks or pages via `block_id` query param
- Comment object has: id, parent, discussion_id, rich_text, created_time, created_by
- List endpoint is paginated

## Technical Details
- Comment struct: id, object, parent, discussion_id, rich_text, created_time, created_by, last_edited_time
- GET /v1/comments?block_id={id} - paginated
- POST /v1/comments - body: { parent: { page_id } | discussion_id, rich_text: [...] }
- GET /v1/comments/{comment_id}
- DELETE /v1/comments/{comment_id}
- Rich text: array of { type: "text", text: { content: "..." } }
