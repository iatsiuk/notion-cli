# 02 - API Client: HTTP Client, Authentication, Error Handling

## References
- OpenAPI spec: `docs/openapi.json`
- Live docs: https://developers.notion.com/llms.txt

## Overview
- Create reusable HTTP client for Notion API
- Implement authentication via Bearer token
- Handle API errors with proper error types and exit codes
- Support pagination for list endpoints
- Add request/response logging for --verbose mode

## Context
- Depends on plan 01 (foundation) for config and error types
- All Notion API requests need: Authorization header, Notion-Version header, Content-Type: application/json
- API uses cursor-based pagination with `start_cursor` and `has_more`
- API errors return JSON: `{ "object": "error", "status": 400, "code": "...", "message": "..." }`

- **CRITICAL: every task MUST include tests written BEFORE implementation code**
